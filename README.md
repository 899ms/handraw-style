# 手绘风格与排版图型提示词库（Hand-drawn Style & Layout Prompter）

> **不会描述画风？排不好版面构图？选个编号，一键生成极具辨识度的 AI 生图提示词。**

本项目整理了 **001–274 种手绘风格** 与 **117 种排版图型**（社媒卡、信息图、漫画分镜）。
不管是做小红书爆款图文、公众号题图、知识科普长图，还是绘制多格叙事条漫，你都不需要背诵复杂的画风术语，也不需要费心构思版面结构——**只要选定风格编号与排版编号，告诉 AI 你想表现的主题，就能立即获得经过实测验证的中英双语生图提示词**，直接复制到支持生图的 AI 工具中出图。

## 🌟 核心解决的问题与特色

| 创作痛点 | 本库的解决方案 |
| :--- | :--- |
| **画风描述模糊，每次生成都漂移** | **编号化精准激活**：274 种手绘插画风格体系，告别“可爱一点、文艺一点”的玄学生图。 |
| **版式构图单调，排不出社媒长图** | **117 种排版图型**：19 种社媒卡、30 种数据信息图、68 种漫画分镜，构图版式开箱即用。 |
| **图文不搭，文字塞不进画面** | **双模式随心切换**：支持“纯图模式”（纯插画表现）与“图文模式”（文字与画面一体化构图）。 |
| **模型画风锁死或无法识别** | **智能模型适配**：依据模型生图能力自动判断是否注入核心特征或附带参考图，画面稳定不跑偏。 |

## 这个 Skill 怎么用

1. 打开 [风格图鉴 (STYLES.md)](STYLES.md) 或 [排版图鉴 (LAYOUTS.md)](LAYOUTS.md)，浏览直观效果并挑选编号；
2. 记下喜欢的编号，例如风格 `041`，或图型 `SC-001`；
3. 输入指令给 Skill，例如：
   - 单独调用风格：`041号风格，主题：秋天的第一杯奶茶`
   - 组合排版与风格：`图型：SC-001，风格：041，主题：秋天的第一杯奶茶`
4. 得到带风格名称与版式定义的中英双语提示词；
5. 复制到 Midjourney、DALL-E 3、Stable Diffusion、Flux 等生图 AI 中直接出图。

## 两种模式，随时切换

同一个编号和主题可以随时在两种模式之间切换，无需重新选择风格。

- **纯图模式**：让主题决定画面内容，适合只需要插画、不需要画中文字的场景。示例：`纯图模式，041号风格，主题：秋天的第一杯奶茶`。
- **图文模式**：保留你写下的主题原文，让文字参与画面构图，适合金句、海报与社交媒体配图。示例：`图文模式，267号风格，主题：有很多事你当时想不通，别着急，过段时间你可能就忘了。`。

切换时直接说“切换为纯图模式”或“切换为图文模式”即可；不指定时默认使用纯图模式。

### 图文模式演示

下图展示了文字与插图共同构图的效果；它仅作为图文模式演示，不绑定任何编号风格。

![图文模式演示：鸭子与手写文字](images/graphic-text-mode-demo.webp)

Skill 默认只负责把想法变成提示词；你明确要求“生图”时，会先判断当前生图模型能否仅凭风格名称激活画风。能激活就不传参考图，不能确认或不能激活就传对应编号的单图，避免模型把参考图中的主体和构图一起锁死。

当前已按 `gpt-image-2` 建立首轮能力清单，生图优先级为：作者名称 + 风格名称 → 再加正向核心风格特征 → 最后传对应编号的单图。像 `001` 这类可由名称激活的风格不传图；没有核心特征或仍不足以激活的编号才传图。这个判断与作者是否著名、是否在世无关。

导入的新风格资源按每 200 个编号分目录保存：例如 `001–200` 在 `images/individual/001-200/`，`201–400` 在 `images/individual/201-400/`。同一编号的单图和四宫格参考图始终在同一个目录。
